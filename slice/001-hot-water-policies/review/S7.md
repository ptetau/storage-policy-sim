# Review S7: code

- minor: [requirement] StoragePolicySim/PolicyCommands.lean:203 `PolicyLine.home` applies each typed value over the home whatever its place, so `--pv 6 --home family` gives the 6 kW panel and not the 8 kW array of `family`. D20 says `--home` sets every home value at once and an option after it changes one value, so a value typed before `--home` should not survive. The README says "whatever the order", so the choice is open to the owner: either keep each option's position in `PolicyLine` and let `--home` reset the earlier values, or leave it and state it in the spec.
- minor: [architecture] StoragePolicySim/HomeSim.lean:47 `tankOf` builds a `TankConfig` from a capacity and an element power, so it belongs with `defaultTank` in `HotWater.lean`, next to the other tank values. `PolicyCommands.lean:225` already reaches into `HomeSim` for it. Fix: move it to `HotWater.lean`.
- minor: [architecture] StoragePolicySim/HomeSim.lean:55 `flexKwh := min 3.0 loadKwh` in `northHome` is dead for the two homes that use it (12 and 30 kWh of load), and D20 gives no flexible load for `small` and `family`. Fix: take `defaultHome.site.flexKwh` and drop the `min`.
- minor: [architecture] StoragePolicySim/Policy.lean:3 the header comment runs to 145 characters and breaks mid-sentence at line 4. Line 176 here and `HomeSim.lean:253` pass 100 characters. Fix: rewrap them.
