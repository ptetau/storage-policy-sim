# Review S8: tests

- major: [tests] test_001_S8_R24_static_flex_start_11_in_run The acceptance line is about the option `--flex-start 11`, but the test reads the library run only, and the only test that runs the command with the option (the bounds test) checks the exit code alone. A command that accepts `--flex-start` and ignores it passes every S8 test. Fix: run `sim policy run --flex-start 11` (static policy) as a process and compare a result line that the start hour changes (for example `import`, or `self-consumption`) with the same line of `runHome` for a static policy with `flexStart` 11, and check that it differs from the default run on the same seed and days.
- minor: [tests] test_001_S8_R25_dynamic_keeps_heating_rather_than_third_start D26 says the dynamic policy takes grid energy for an hour with no surplus only if it would else need a third start. No test covers the other side: a tank that asked in the last hour, with 0 or 1 starts today, no surplus, and above its low level. A version that always keeps heating from the grid passes all tests. Fix: add an observation test with 1 start, asked last hour, no surplus, a tank between the low level and the target, and assert a request of 0.
- minor: [tests] test_001_S8_R24_precomputed_flex_in_sunny_hours The test uses a tank that needs no heat, so it cannot tell "the sunniest hours that the forecast leaves after the tanks" from "the sunniest hours of the forecast". A version that ignores what the tanks took passes. Fix: add a plan call with a tank that needs heat in the sunniest hours, and assert that the flexible load avoids the hours where the forecast left is lower than in other hours, and still adds up to the day's energy.
