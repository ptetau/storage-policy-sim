# Review S1: tests

- major: [tests] test_001_S1_R6_hours_hold_scenario_solar_and_house_load The test checks the house load of each hour against the base load of the scenario plus the flexible load that the run itself reports for that hour. A wrong version that drops the flexible load, or runs it twice, passes, and so do all later tests that read the run (they read the same hours). The acceptance line says that each hour holds the house load of the scenario hour. Fix: for the default static policy (flexible load from hour 18), compare the house load of each hour with the base load plus the flexible load of the scenario hour. The test can also check that the flexible energy of each day equals the 3.0 kWh of the site.
- minor: [tests] test_001_S1_R2_default_static_window_hours_10_to_13 The test asks only for the 3.0 kW element of the default tank. A wrong version that writes 3.0 in the window, instead of the element power of the tank, passes. R2 says the tank asks for the element power. Fix: add a check with a tank whose element is not 3.0 kW (for example 2.0 kW) and expect that power in the window.
