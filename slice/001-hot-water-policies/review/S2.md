# Review S2: code

- minor: [requirement] StoragePolicySim/PolicyCommands.lean:131 (`PolicyLine.policyOf`) The command always sets the target to 10.5 and the low level to 5.25 when the person gives no `--target` or `--low`, so `--tank 20` heats a 20 kWh tank only to 10.5 kWh, and `--tank 5` gives a low level above the capacity. The interface says that a missing target is the capacity of the tank and a missing low level is half of it. Leave the arrays empty when the option is not typed, or derive the default from the typed tank values.
- minor: [architecture] StoragePolicySim/PolicyCommands.lean:158 (`policyRunLines`) The `policy` line prints the typed name string, and `PolicyLine.policyOf` falls back to `static` on any other string. Print `Policy.name` of the policy that runs, so that the printed name and the run cannot differ.
- minor: [architecture] StoragePolicySim/PolicyCommands.lean:223 (`forecastRun`) The reading step uses `hourOption 0`, an option with the range -1 to -1, only to read a whole number. Give the reading step an option without a false range, so that a later change of the range code does not use it.
