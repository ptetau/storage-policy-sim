- minor: [architecture] StoragePolicySim/PhysTank.lean:44 The 45 degrees of the litres rule (D8) and the 42 degrees of the loss rule (line 46) are bare numbers in the body. HotWater.lean names such values as private constants with a doc line (for example `seasonSwing`). Name them, for example `litresDeltaC` and `lossDeltaC`.
- minor: [architecture] StoragePolicySim/PhysTank.lean:111 The thermostat decision is inline in `physTankStep`. HotWater.lean keeps the same rule in a private helper `thermostatOn`, which names the rule of the PhysThermostat machine (T1, T2 and the stay-on). Move it to a private helper, so that the step reads as the order of the spec.
