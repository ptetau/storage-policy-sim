# Review S4: code (R11 physics run, R12 `--model` option)

- major: [requirement] StoragePolicySim/PhysRun.lean:217 `coldHours` counts each step (a quarter of an hour) in which a tank is below its floor share, so a cold hour counts up to 4 times. R11 says the totals have the meaning of spec 001 R8, and spec 001 D27 says a cold hour is an hour that one tank ends below its floor. The `cold-hours` of `sim policy run` and `robust` is then 4 times too high in a cold spell. Count one cold hour for each tank and hour, from the state of the tank at the last step of the hour (`quarter` 3).
- minor: [architecture] StoragePolicySim/PolicyCommands.lean:500 The command hard-codes 4 records for each hour of the physics run, and the index `perHour * (hoursInDay * day + hour)`, while `stepsPerHour` is private to `PhysRun`. Export one public constant for the steps in an hour (beside `stepsPerDay` in `PhysWeather`) and use it in both files, so the layout of the records has one owner.
- minor: [architecture] StoragePolicySim/PhysRun.lean:18 `stepLengthHours` is the third private copy of the 0.25 h step (`PhysTank.stepHours`, `PhysAppliances.stepHours`). Define the step length once, next to `stepsPerDay`, and use it in the three files.
- minor: [architecture] StoragePolicySim/PolicyCommands.lean:294 The comment of `PolicyLine.physics` says "True when `--model physics` is typed last". The function only tests the stored model name. Say "True when the model of the options is physics".
